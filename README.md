# ماشین حساب مهندسی (ترمینالی)

یک ماشین حساب مهندسی ساده با زبان **پایتون** که داخل ترمینال اجرا می‌شود. عبارت ریاضی را می‌گیرد، با رعایت اولویت عملگرها محاسبه می‌کند و نتیجه را چاپ می‌کند.

## امکانات

| عملگر / تابع | توضیح | مثال |
|---|---|---|
| `+` `-` `*` `/` | جمع، تفریق، ضرب، تقسیم | `2+3*4` ← `14` |
| `mod` | باقی‌مانده | `10 mod 3` ← `1` |
| `^` | توان | `2^10` ← `1024` |
| `sqrt(x)` یا `√x` | رادیکال | `sqrt(16)` ← `4` |
| `%` | درصد | `200*15%` ← `30` |
| `abs(x)` | قدر مطلق | `abs(-7)` ← `7` |
| `sin(x)` `cos(x)` `tan(x)` | مثلثاتی (زاویه به درجه) | `sin(30)` ← `0.5` |
| `pi` | عدد پی | `2*pi` ← `6.28318530718` |
| `( )` | پرانتز | `(2+3)*4` ← `20` |

## نحوه اجرا

پایتون 3.7 یا بالاتر لازم است و به کتابخانه‌ی اضافه نیازی نیست.

```
python calc.py              # حالت تعاملی
python calc.py "2+3*4"      # محاسبه‌ی مستقیم
python calc.py -h           # راهنما
```

نمونه در حالت تعاملی:

```
calc> (5 + 3) * 2 ^ 3
= 64
calc> exit
```

اگر عبارت اشتباه باشد (مثل `1/0`) برنامه پیام خطا می‌دهد و بسته نمی‌شود.

## نحوه کارکرد

1. **توکن‌سازی:** عبارت به قطعه‌های کوچک (عدد، عملگر، تابع) شکسته می‌شود.
2. **محاسبه:** یک تجزیه‌گر (Parser) توکن‌ها را به ترتیب اولویت عملگرها می‌خواند و محاسبه می‌کند.
3. **چاپ:** نتیجه مرتب می‌شود و نمایش داده می‌شود.

از `eval` استفاده نشده است. توضیح کامل خط‌به‌خط کد در فایل `calc_tozihat.pdf` آمده است.
